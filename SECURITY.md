# Security Posture — Royal Exotic Farms

## In place
- **Transport:** HTTPS terminated at Render; `ProxyFix` trusts one proxy hop so scheme/host/IP are correct. **HSTS** (`max-age=31536000; includeSubDomains`) sent on secure responses in production.
- **Headers:** `Content-Security-Policy` (script `'self'`; style `'self' 'unsafe-inline'` + Google Fonts; img `'self' data:`; `frame-ancestors 'none'`; `object-src 'none'`), `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, `Cross-Origin-Opener-Policy`.
- **CSRF:** Flask-WTF `CSRFProtect` global; every form posts a token. The `/track` beacon is intentionally CSRF-exempt (append-only, size-capped, non-mutating to business data).
- **Cookies/session:** production sets `Secure`, `HttpOnly`, `SameSite=Lax`.
- **Spam:** honeypot (`website`) on every form; failed honeypot returns success without persisting.
- **Input:** WTForms validation + length caps; Markdown insights sanitized with a strict **bleach** allow-list before render.
- **Secrets:** environment-only; `SECRET_KEY` generated by Render; no secrets in the repo.
- **DB:** parameterized via SQLAlchemy ORM (no raw SQL); `pool_pre_ping` + `pool_recycle`.

## CSP notes
`script-src 'self'` does **not** break JSON-LD structured data — `application/ld+json` is a data block exempt from `script-src`. `'unsafe-inline'` is scoped to **style** only (a few inline `style` attributes); scripts remain strict. If you later remove inline style attributes, tighten to `style-src 'self' https://fonts.googleapis.com`. Override the whole policy per-environment with the `CONTENT_SECURITY_POLICY` env var.

## Recommended hardening (post-launch, prioritized)
1. **Rate limiting** *(highest value)* — public `POST` endpoints (`/…/submit`, `/track`) have no throttle beyond the honeypot. Add **Flask-Limiter** with a **Redis** store (required for correctness across the 3 gunicorn workers; in-memory is per-worker and inconsistent). Suggested: submits `5/minute/IP`, `/track` `120/minute/IP`, safe methods exempt. Tune generously — a false positive blocks a real buyer, which is worse than the spam it stops.
2. **Edge protection** — front the site with Cloudflare (or Render's DDoS protection) for volumetric abuse and bot filtering on `/track`.
3. **Error monitoring** — add Sentry (see `MONITORING.md`) so 500s are captured with context, not just logged.
4. **Email deliverability/anti-spoof** — publish SPF, DKIM, DMARC for the sender domain so inquiry notifications and acknowledgements are trusted.
5. **Analytics retention** — schedule pruning of `analytics_events` (e.g. keep 180 days) to bound table growth and reduce PII surface.
6. **Dependency hygiene** — pin a lockfile (`pip-compile`/`pip freeze`) and enable Dependabot/`pip-audit` in CI.

## Data & privacy
- Stored per submission: name, company, email, phone, country, message, plus IP + user-agent for spam triage. Ensure the privacy page reflects this and set a retention policy. Provide a deletion path on request.
